# Skill: Shoppable Script Draft

**Trigger:** after morning scan, or on demand.

1. Pick the top 3 leads + matching menu items.
2. Draft a script per lead:
   - Hook (first 2 seconds, visual product moment)
   - Demo (taste/quality, 3-5s)
   - Price or scarcity
   - CTA: "tap the bag" / "shop in bio" linking the TikTok Shop product
3. Save as `ContentDraft` with status PENDING_APPROVAL.
4. Ping owner for approval. On approve → status APPROVED → hand to commerce engine to create TikTok product draft.

**Never** post or schedule without APPROVED status.
